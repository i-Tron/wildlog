# 野录 WildLog

野录（WildLog）是一个编辑发布型观鸟攻略合集原型，当前以上海为先，按资料质量逐步扩展地区。原型保留搜索、地区/季节/难度筛选、详情目录、本地收藏和原生分享/复制链接能力。

## 启动

无需构建工具。进入项目目录后运行任意静态文件服务器：

```bash
cd ~/studio/wildlog
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。也可以直接在浏览器打开 `index.html`，但使用服务器更接近实际访问方式。

## 目录结构

- `index.html`：当前可运行的单页静态原型，包含样式、交互和示例内容数据。
- `PRODUCT.md`：产品边界、内容原则、待核实假设和后续验证顺序。
- `skills/bird-guide/SKILL.md`：攻略编辑与核验工作流约束。
- `README.md`：项目启动、维护和边界说明。

## 内容更新流程

1. 在 `index.html` 的 `data` 数组中新增或修改攻略记录，保持稳定 `id`、标题、地区、季节、难度、描述和 `status`。
2. 新内容先标记为 `演示内容`、`待核验` 或 `资料缺口`，并在 `PRODUCT.md` 或后续内容记录中补充来源与核验说明。
3. 对路线进入方式、开放规则、潮汐、观察礼仪和鸟种/鸟讯逐条核验；证据充分后才可标记为 `已核验`。
4. 浏览器检查搜索、筛选、详情、收藏和分享/复制链接，再提交变更。

## 当前原型边界

这是可打开的静态原型，不包含后端、账号、投稿、评论、实时鸟讯、活动报名、支付、内容管理后台或数据库。示例路线与状态用于演示信息架构；盐城东台条子泥保留为资料缺口占位，未宣称复用任何不可访问的原文。市场、用户、竞品和商业化材料中的数字仍是待核实假设。
