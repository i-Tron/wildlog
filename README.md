# 野录 WildLog

野录（WildLog）是一个编辑发布型观鸟攻略合集原型，当前以上海为先，按资料质量逐步扩展地区。原型保留搜索、地区/季节/难度筛选、详情目录、本地收藏和原生分享/复制链接能力。

## 启动

无需构建工具。进入项目目录后运行任意静态文件服务器：

```bash
cd ~/studio/wildlog
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。也可以直接在浏览器打开 `index.html`，但使用服务器更接近实际访问方式。

## 目录结构

- `index.html`：当前可运行的单页静态原型，包含样式、交互和首批三篇攻略卡片。
- `PRODUCT.md`：产品边界、内容原则、待核实假设和后续验证顺序。
- `skills/bird-guide/SKILL.md`：攻略编辑、公开资料交叉验证、时效字段、合规边界和 QA 验收契约。
- `content/guides/index.html`：可直接打开的首批攻略索引；同目录三份 HTML 是可读页面，Markdown 是内容源，`index.json` 是批量扩展入口。
- `README.md`：项目启动、维护和边界说明。

## 内容更新流程

1. 在 `content/guides/` 新建 Markdown 正文，并在 `index.json` 增加稳定 `article_id`、`slug`、月份、地区、状态、`last_checked_at`、`next_review_at` 与来源 ID。
2. 按 `skills/bird-guide/SKILL.md` 为关键字段保存来源 URL、来源日期、检索日期、有效期、置信度和是否待复核；至少使用管理/法规类与生态/观察类两类来源。
3. 生成对应 HTML 页面并更新 `content/guides/index.html`；`index.html` 的卡片只展示摘要，详情链接指向可直接打开的页面。
4. 新内容先标记为 `待核验` 或 `资料缺口`；对路线进入方式、开放规则、潮汐、观察礼仪和鸟种/鸟讯逐条核验，证据充分并完成人工复核后才可标记 `approved/published`。
5. 分享仅在系统分享或剪贴板写入成功后提示成功；失败时显示手工复制链接，本地文件链接仅适用于当前电脑。收藏存储不可用时仍可在当前页面使用。
6. 浏览器检查搜索、筛选、详情、收藏和分享/复制链接；同时打开 `content/guides/index.html` 和三篇详情页检查来源链接、表格横向滚动和待核验状态，再提交变更。

## 当前原型边界

这是可打开的静态原型，不包含后端、账号、投稿、评论、实时鸟讯、活动报名、支付、内容管理后台或数据库。示例路线与状态用于演示信息架构；首批崇明东滩、东台条子泥、杭州湾/钱塘江湾三篇均由公开资料整理，仍标记待核验；不含私人行程、预订或联系方式。市场、用户、竞品和商业化材料中的数字仍是待核实假设。
